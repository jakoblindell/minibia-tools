World Compendium

Monsters, items, NPCs, spells, runes, achievements and spawn locations, browsable in one place — built from library.json and spawns.json.

This is a design database, not client data — grepping src/ found no fetch for library.json or spawns.json anywhere in the game client, so nothing on this page is something a player can see in-game. It's reference material only.
Gold-per-kill = each loot line's drop chance × average quantity × best NPC sell price, summed. – of loot lines matched a known sell price in library.json's item list — unmatched drops (usually quest items, decorations, or items no NPC buys) count as 0gp, so real value may run slightly higher for monsters with unmatched drops.

Scroll to zoom, drag to pan, hover a dot for details. Terrain is decoded from the client's own minimap.bin at full 1 px = 1 tile resolution — colors and coverage match what the game itself would show, not a live render. Use ▲/▼ to change floor (16 floors, z=7 is ground). Only the main explored region is drawn; a few far-flung spawn clusters sit outside it. Spawn data has no floor axis, so the same spawn dots are shown on every floor — the floor control only swaps the terrain behind them.
